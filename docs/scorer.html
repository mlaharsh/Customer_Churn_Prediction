    04 · What this is

    The same model, not a lookalike.

    The browser scorer is a deployment surface for the trained pipeline, not a new model and not a mock-up. The native Streamlit workbench remains the full reference implementation.

    01

    Exported coefficients

    The logistic-regression intercept, one-hot coefficients, imputer medians, and scaler parameters come directly from models/churn_model.joblib.

    A Python export script regenerates the browser data so the static page cannot drift silently.

    02

    Identical preprocessing

    The browser derives the same AvgMonthlySpend, ServiceCount, and IsNewCustomer fields, then applies median imputation, standard scaling, and unknown-category handling.

    Example profiles are checked against the Python pipeline's probabilities.

    03

    Honest evaluation

    The threshold lab replays saved holdout predictions from the original evaluation split. It does not tune on the holdout set or claim production readiness.

    Use the model card and deployment notes before applying scores to real customers.
